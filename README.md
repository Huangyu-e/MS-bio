# MS-bio
This repository provides the code accompanying the study “Mutational signature-based biomarker to predict the response of immune checkpoint inhibitors therapy in cancers.” MS-bio is a biomarker comprising six mutational signatures for predicting responses to immune checkpoint inhibitors. It outperformed existing biomarkers in internal and external validation, achieving an accuracy of up to 0.82.
